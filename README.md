# FlutterFFI

## Introduction

Welcome to the FlutterFFI project! As a full-stack engineer proficient in Python, Golang, Vue, Clutter, Kotlin, Swift, and Objective-C, I am deeply passionate about building scalable applications. My focus is on wireless communication technologies including Bluetooth Mesh, Matter, and ZigBee protocols. Additionally, I have worked extensively on projects involving audio-video synchronization and Bluetooth hardware interaction. This repository is aimed at showcasing my work, collaborating with others, and serving as a platform for learning and development.
